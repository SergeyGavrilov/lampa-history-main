# История просмотров на главной Lampa

Плагин добавляет на главную ряд «История просмотров» с последними 20 фильмами и сериалами из штатной истории Lampa. Карточки открываются обычным способом; позицию просмотра и выбор источника обрабатывает сама Lampa. Если история пуста, ряд не показывается. Данные берутся из Lampa, в том числе из её синхронизированных закладок при включённой синхронизации; отдельный сервер для истории не нужен.

## Установка

1. Разместите файл [history.js](history.js) по публичному HTTPS-адресу с прямым доступом к файлу, например через GitHub Pages. Сам файл в этом проекте ещё не опубликован.
2. В Lampa откройте «Настройки → Расширения», добавьте прямую ссылку на `history.js` и включите плагин.
3. Перезапустите Lampa или обновите главную страницу. Посмотрите что-нибудь, если история ещё пуста.

Ряд можно отключить в настройках каналов главной страницы Lampa. Совместимость рассчитана на версии с API `Lampa.ContentRows` и `Lampa.Favorite`; в других сборках плагин не активируется. История отражает штатный список Lampa, а не отдельный журнал каждого запуска. Другие плагины, добавляющие ряды в начало, могут повлиять на их порядок.
